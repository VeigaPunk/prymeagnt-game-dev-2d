# game-dev-2d — domain corpus

Reference corpus of the **game-dev-2d** shokunin lane: the craft master's
notebook for 2D game production verified by executable headless fixtures.

Purposes: (1) reference guide — fixtures carry reproduction commands and
expected exit signatures; (2) discovery corpus for new production moves;
(3) inspiration source — failed approaches stay in the ledger as negative
results.

Provenance: fixtures seeded from the games-engine-mechanics research
direction (r15-toggle, commit c32adb1); seed knowledge records the standing
fixture discipline and the verified capability ladder. Round history will
accumulate on craft/* branches of this repo; ledger in .shokunin/MANIFEST.json
there.

Upstream: https://github.com/VeigaPunk/prymeagnt-game-dev-2d — local
execution references it with: git fetch game-dev-2d main
